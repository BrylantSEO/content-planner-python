# Central Search Intent (CSI)

## Co to jest?

**CSI = Central Entity + Source Context**

Central Search Intent to unifikacja Encji Centralnej z Kontekstem Źródłowym. Reprezentuje główną intencję użytkowników odwiedzających witrynę.

### Central Entity (CE) - "O czym jest strona?"

Encja, która pojawia się **site-wide** - na każdej stronie, we wszystkich n-gramach witryny.

### Source Context (SC) - "Z jakiej perspektywy?"

Kontekst źródłowy określa **tożsamość marki** i jej cel. Ta sama CE może mieć różne SC:

## Cel
- Zdefiniować "o czym jest strona" (Central Entity)
- Określić "z jakiej perspektywy marka mówi o CE" (Source Context)
- Połączyć oba elementy w główną intencję wyszukiwania (CSI)
- Zapewnić spójność całej strategii contentowej
